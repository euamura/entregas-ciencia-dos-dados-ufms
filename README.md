# 📚 Entregas — Ciência dos Dados · UFMS

Repositório com as entregas práticas do curso de **Tecnologia em Ciência dos Dados** da **Universidade Federal de Mato Grosso do Sul (UFMS)**.

Cada projeto está organizado por disciplina, com código-fonte e README individual explicando objetivos, funcionamento e tecnologias utilizadas.

---

## 🗂️ Estrutura do Repositório

```
entregas-ciencia-dos-dados-ufms/
│
├── algoritmos2/
│   ├── fila-circular-interativa/          # Fila circular com menu interativo (Python)
│   ├── separador-pares-impares/           # Separação de listas aleatórias (Python)
│   └── soma-recursiva-numeros-naturais/   # Soma recursiva com validação (Python)
│
├── programacao-orientada-a-objetos/
│   ├── sistema-cadastro-hortifruti/       # Cadastro e busca de produtos (Python)
│   └── simulador-conta-corrente/          # Simulação de conta bancária em Java (Java)
│
└── desenvolvimento-web/
    └── gerenciador-tarefas-diarias/       # App de tarefas com Vue.js e Bootstrap (HTML/JS)
```
